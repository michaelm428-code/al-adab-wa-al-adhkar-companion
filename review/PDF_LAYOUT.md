# تنسيق نسخ PDF للمراجعة العلمية

هذا الملف يحفظ قواعد إخراج نسخ المراجعة العلمية بصيغة PDF حتى يمكن إعادة إنتاجها في محادثات لاحقة بصورة متسقة.

## الغرض

نسخة PDF للمراجعة ليست مصدرًا بحثيًا مستقلًا. مصدرها هو ملفات `publication/` الحالية، وتُنشأ لتسهيل مراجعة المستخدم والمراجع العلمي.

## تنسيق الغلاف

- المقاس: A4.
- الاتجاه: عربي RTL.
- **يجب أن يكون محتوى الغلاف في H0001 وH0002 والمداخل اللاحقة متمركزًا أفقيًا فعلًا في الصفحة.**
- يشمل التمركز:
  - اسم المشروع؛
  - عنوان الكتاب؛
  - رقم الموضوع وعنوانه؛
  - رقم الحديث؛
  - شارة «نسخة للمراجعة العلمية»؛
  - بيان حالة النسخة؛
  - سطر بيانات النسخة أسفل الغلاف.
- لا يُعتمد على عناصر RTL ذات عرض تلقائي داخل Flexbox للتمركز؛ فقد تسبب إزاحة النص إلى اليمين أو قصه.
- تُستخدم كتل بعرض الصفحة المتاح مع `text-align:center`، وتكون شارة المراجعة ذات عرض ثابت أو معلوم ومتمركزة بهوامش تلقائية.
- لا يجوز أن يلامس النص إطار الغلاف أو يُقص عند الحافة.

## بنية ملف المراجعة لكل حديث

1. غلاف الحديث.
2. بطاقة المراجعة العلمية.
3. النص العربي المعد للنشر.
4. صفحة ملاحظات المراجع.

## الحزمة المجمعة

عند جمع عدة أحاديث:

1. غلاف عام للحزمة.
2. ملف المراجعة الكامل لكل حديث بالترتيب.
3. لا تُدمج أغلفة الأحاديث أو تحذف؛ ليستطيع المراجع فصل كل حديث بصريًا.

## التحقق البصري الإلزامي

بعد إنشاء PDF:

1. يُرندر الملف إلى صور.
2. تُفحص صفحة غلاف كل حديث بصريًا.
3. يُتحقق من:
   - التمركز الأفقي؛
   - عدم القص أو التداخل؛
   - سلامة العربية والتشكيل؛
   - اتساق المسافات والإطار؛
   - بقاء صفحات المحتوى دون تغيير غير مقصود.
4. إذا كان التعديل متعلقًا بالغلاف فقط، يُفضَّل استبدال صفحة الغلاف وحدها والإبقاء على بقية صفحات PDF الأصلية كما هي.

## الحالة الحالية

في 2026-10-04 صُححت أغلفة H0001 وH0002 بعد اكتشاف انزياح عناصر الغلاف إلى اليمين بسبب تخطيط RTL. أُعيد فحص الغلافين بصريًا وأصبحا متمركزين دون قص.
