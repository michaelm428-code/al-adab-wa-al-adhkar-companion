# تدقيق نسخة النشر — H0002

**ملف البحث:** `hadith/001-02.md`  
**ملف النشر:** `publication/001-02.md`  
**تاريخ التدقيق:** 2026-10-02  
**النتيجة:** **اجتاز بوابة التوثيق — جاهز للمراجعة النهائية**

## نطاق التدقيق

تمت مراجعة النسخة المعدة للنشر مقابل ملف البحث وسجل المصادر، مع تطبيق قاعدة أن النص المنشور لا يحتوي على عناصر بحثية غير موثقة.

## نتائج الفحص

- [x] نص الحديث مطابق للفظ *الأذكار والآداب*.
- [x] هامش «متفق عليه» تحقق بمراجعة البخاري ومسلم.
- [x] الرواية الأطول المدرجة من البخاري 71.
- [x] لم تُدمج ألفاظ الطرق المختلفة في نص مركب.
- [x] سياقات المدينة ودمشق صيغت بوصفها مواضع لرواية معاوية للحديث، ولم يُجعل منبر دمشق موضعًا لقول النبي ﷺ.
- [x] عدم العثور على تاريخ محدد صيغ بعبارة مقيدة بحدود الطرق المراجعة.
- [x] شرح الدرر السنية محفوظ من النص الذي زوّد به المستخدم.
- [x] الجمل الختامية غير المنسوبة في شرح الدرر لم تُحوَّل إلى فوائد مستقلة.
- [x] المفردات المنشورة منسوبة إلى ابن حجر والعيني.
- [x] شروح ابن حجر والنووي والعيني وابن عبد البر وابن باز منسوبة وقابلة للتتبع.
- [x] جميع الفوائد المدرجة منسوبة إلى علماء معينين.
- [x] جميع التطبيقات المدرجة منسوبة إلى مصدر رسمي للشيخ ابن باز.
- [x] لم تدخل أرقام ابن ماجه وأحمد التي ذكرتها صفحة الدرر في نص النشر بوصفها حقائق مستقلة غير مراجعة.
- [x] النص الموجه للقارئ عربي بالكامل.

## القرار

النسخة **جاهزة للمراجعة النهائية من جهة التوثيق**.

لا تعني هذه الحالة اعتمادها النهائي للطباعة؛ يبقى اعتماد الأسلوب، والحجم، وترتيب المادة للمستخدم والمراجع العلمي.
