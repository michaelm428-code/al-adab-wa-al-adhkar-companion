# Sources

This directory tracks the sources used across the project.

## Purpose

The source system should make it possible to answer two questions quickly:

1. **What source supports this claim?**
2. **Can another researcher locate and verify the same passage?**

Use stable source IDs from [source-register.md](source-register.md) when a source is reused across entries.

## Source priority

Prefer:

1. Primary hadith collections.
2. Classical hadith commentaries.
3. Original books of recognized scholars.
4. Official scholarly sources.
5. Dorar al-Sunniyyah.
6. Reliable secondary research tools.

Secondary tools and Dorar can be excellent gateways. They do not automatically count as original-source verification for an attribution to another scholar.

## What to record

For books, record as available:

- author;
- title;
- editor;
- edition;
- publisher;
- publication year;
- volume/page or other stable locator;
- reliable digital copy or catalog link.

For websites, record:

- organization or author;
- page title;
- direct URL;
- date accessed;
- whether the page reproduces a primary source or merely summarizes it.

For hadith databases, record the collection and hadith locator in addition to the database URL.

## Source IDs

Use the form:

`SRC-0001`, `SRC-0002`, ...

A source ID identifies the source or edition, not an individual claim. Individual claims should have evidence IDs inside hadith entries.
